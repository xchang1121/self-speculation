# Upstream attribution

This project is a focused reorganization of concepts and implementation work
from **SPORK: Self-Speculative Forking to Accelerate Agentic LLM Inference**.

- Upstream authors: Huajun Bai, Weiwei Lv, Huichuan Zheng, Youyou Lu, Jiwu Shu
- Upstream repository: https://github.com/baihuajun24/spork
- Starting fork: https://github.com/xchang1121/spork
- Paper: https://arxiv.org/abs/2607.03333
- Upstream license: MIT, retained in `LICENSE`

The Git history before the `self-speculation` refactor is intentionally
preserved so that individual upstream changes remain attributable.
